PROJECT GOAL

Steps Towards More Accessible TMS

This project uses computational modeling software to simulate neuronal responses to transcranial magnetic stimulation. The goal is to identify methods for optimizing stimulation parameters to greatly reduce the required power and, ultimately, make TMS treatment more accessible.
